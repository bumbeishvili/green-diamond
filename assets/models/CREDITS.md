Compiled 2026-09-23. Every file below was verified (GLB magic + JSON chunk parsed) and is listed with its source, author and license in `manifest.json`.

**CC-BY 3.0 assets require attribution** in the game's credits screen or README. Copy the lines in the CC-BY section. CC0 assets need no attribution, but crediting the authors (especially Quaternius) is appreciated.

Changes made for this project are noted per item: format conversion, animation merging, splitting multi-model files, texture re-encoding and material fixes. None of them change the licensing terms.
